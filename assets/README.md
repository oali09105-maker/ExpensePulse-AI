# Assets Needed Before Building

Drop your final artwork here with these EXACT filenames (referenced by app.json):

- `icon.png`      — 1024x1024, app icon (used for both iOS icon and Android adaptive icon foreground)
- `splash.png`     — recommended 1242x2436 (or similar), shown on app launch
- `banner.png`     — your promotional/store banner asset (referenced via app.json's `extra.brandBanner`
                      for your own use in store listing tooling; not auto-applied by Expo itself)

Background color used behind icon/splash: #0B1F17 (matches the in-app Emerald & Gold dark theme).
